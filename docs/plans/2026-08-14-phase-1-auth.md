# Phase 1 — Auth & Routing Plan

> **Executor:** an agent with repo context. Compact; inline code only where non-obvious. Test-first for logic. **All new components/hooks/handlers carry explicit return types** (`: ReactNode`, `: Promise<void>`), matching existing files.
> **Do NOT push/PR/merge.** Phase ends by running the dev server. Live login needs the user's public Firebase web config in `.env.local`; all tests run without it (Firebase is mocked behind the `authClient` seam).

**Goal:** Firebase auth (email/password + Google) with an HttpOnly session, a Node-runtime **proxy** protecting `/seller/*` + `/checkout` (intent capture + role gating), login/register/seller-register UI, logout, and an app shell.

**Verified stack (bundled Next 16.3 docs):** `firebase@12.16`, `jose@6.2.8`. **Next 16 renamed `middleware.ts` → `proxy.ts`** (`export function proxy`, **Node.js runtime**, no `runtime` export — it throws). `cookies()` is async. Primitives are **`@base-ui/react`** (shadcn `base-nova` style) — do NOT import `@radix-ui/*`.

**Session model:** client signs in with Firebase → sends ID token to a server endpoint → server verifies it against Google's JWKS (`jose`, no Admin SDK) → mints our **HS256 session JWT** `{ sub, email, role }` → HttpOnly cookie. `proxy.ts` verifies that JWT (jose on Node). Role/profile live in the in-app BFF keyed by `uid`. **Role is assigned server-side by which endpoint is called, never from a client-supplied field on the login endpoint.**

**Shared types** (`src/types/index.ts`): `type Role = 'buyer' | 'seller'`; `interface SessionUser { uid: string; email?: string; role: Role }`. Both `/api/auth/session` and `/api/auth/me` return `{ user: SessionUser | null }` (map JWT `sub → uid`).

### T4 — Session JWT + Firebase verify (test-first)
`src/lib/server/session.ts` — HS256 session token; secret validated lazily (build-safe, fails at first use if misconfigured):
```ts
import { SignJWT, jwtVerify } from 'jose'
export type Role = 'buyer' | 'seller'
export interface SessionClaims { sub: string; email?: string; role: Role }
const ISS = 'trade-sphere'

function getSecret(): Uint8Array {
  const raw = process.env.SESSION_JWT_SECRET
  if (!raw || Buffer.byteLength(raw) < 32) throw new Error('SESSION_JWT_SECRET must be >= 32 bytes')
  return new TextEncoder().encode(raw)
}
export async function createSessionJwt(c: SessionClaims): Promise<string> {
  return new SignJWT({ email: c.email, role: c.role })
    .setProtectedHeader({ alg: 'HS256' }).setSubject(c.sub)
    .setIssuedAt().setIssuer(ISS).setAudience(ISS).setExpirationTime('7d').sign(getSecret())
}
export async function verifySessionJwt(token: string): Promise<SessionClaims> {
  const { payload } = await jwtVerify(token, getSecret(), { algorithms: ['HS256'], issuer: ISS, audience: ISS })
  return { sub: payload.sub as string, email: payload.email as string | undefined, role: payload.role as Role }
}
```
`src/lib/server/firebase-verify.ts` — verify Firebase ID token via Google JWKS (no Admin SDK):
```ts
import { jwtVerify, createRemoteJWKSet, type JWTPayload } from 'jose'
const PROJECT_ID = process.env.NEXT_PUBLIC_FIREBASE_PROJECT_ID
const JWKS = createRemoteJWKSet(
  new URL('https://www.googleapis.com/service_accounts/v1/jwk/securetoken@system.gserviceaccount.com'),
)
export interface FirebaseIdToken extends JWTPayload { sub: string; email?: string }
export async function verifyFirebaseIdToken(token: string): Promise<FirebaseIdToken> {
  const { payload } = await jwtVerify(token, JWKS, {
    issuer: `https://securetoken.google.com/${PROJECT_ID}`, audience: PROJECT_ID!, algorithms: ['RS256'],
  })
  if (!payload.sub) throw new Error('missing sub')
  return payload as FirebaseIdToken
}
```
Test `session.ts`: sign→verify round-trip; tampered token throws; short secret throws. Commit: `feat: session jwt + firebase id-token verification`.

### T7 — Firebase client (lazy, SSR-safe)
`src/lib/firebase-client.ts` (`'use client'`): lazy init so nothing runs during SSR/prerender:
```ts
'use client'
import { initializeApp, getApps, getApp, type FirebaseApp } from 'firebase/app'
import { getAuth, setPersistence, inMemoryPersistence, type Auth } from 'firebase/auth'
let cached: { auth: Auth; ready: Promise<void> } | null = null
export function getFirebaseAuth(): { auth: Auth; ready: Promise<void> } {
  if (cached) return cached
  const app: FirebaseApp = getApps().length ? getApp() : initializeApp({
    apiKey: process.env.NEXT_PUBLIC_FIREBASE_API_KEY!,
    authDomain: process.env.NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN!,
    projectId: process.env.NEXT_PUBLIC_FIREBASE_PROJECT_ID!,
    appId: process.env.NEXT_PUBLIC_FIREBASE_APP_ID!,
  })
  const auth = getAuth(app)
  // inMemoryPersistence is DELIBERATE: no token in localStorage/IndexedDB (CODING_GUIDELINES §5.1);
  // the HttpOnly cookie is the session of record, re-hydrated via /api/auth/me. Do NOT switch to browserLocal.
  cached = { auth, ready: setPersistence(auth, inMemoryPersistence) }
  return cached
}
```

### T11 — proxy (test-first helper)
`src/lib/server/auth-redirect.ts` — pure, testable:
```ts
export type AuthDecision = { type: 'next' } | { type: 'redirect'; to: string }
const PUBLIC_WITHIN_PROTECTED = ['/seller/register']
export function decideAuth(pathname: string, search: string, session: { role: string } | null): AuthDecision {
  if (PUBLIC_WITHIN_PROTECTED.includes(pathname)) return { type: 'next' }
  if (!session) return { type: 'redirect', to: `/login?returnUrl=${encodeURIComponent(pathname + search)}` }
  if (pathname.startsWith('/seller') && session.role !== 'seller') return { type: 'redirect', to: '/' }
  return { type: 'next' }
}
```
Unit-test: `/seller/register` allowed with no session; no session → redirect to `/login?returnUrl=...`; buyer on `/seller` → `/`; seller on `/seller` → next; any → `/checkout` requires session.
`src/proxy.ts` (NOT middleware.ts; **do not run the codemod-created middleware**): read `session` cookie; if present `verifySessionJwt` in try/catch (invalid → null); call `decideAuth`; on redirect return `NextResponse.redirect(new URL(to, request.url))` (delete cookie if it was present-but-invalid); else `NextResponse.next()`. `export const config = { matcher: ['/seller/:path*', '/checkout'] }`. No `runtime` export. Commit: `feat: proxy for protected routes`.
